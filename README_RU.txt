BatteryTaskbar — модульный рефакторинг

Что изменено:
- Логика чтения заряда разделена на независимые провайдеры.
- Добавлен общий интерфейс IBatteryProvider.
- BatteryProviderManager запускает провайдеры, проверяет проценты и объединяет результаты.
- BatteryService оставлен как совместимый фасад: Program.cs и интерфейс менять не нужно.
- Текущие способы чтения Windows PnP, Windows Battery API, Ajazz, Logitech HID++ и Bluetooth LE перенесены в отдельные файлы.

Важно:
1. Ajazz-адаптер оставлен экспериментальным. Его команды и байт процента не подтверждены для всех моделей.
2. LogitechHidpp.cs не заменяется этим архивом. Текущая проверка длины Output Report в нём всё ещё может пропускать G435.
3. Это архитектурный рефакторинг, а не обещание поддержки всех устройств. Для нового производителя создаётся новый класс, реализующий IBatteryProvider.
4. Все .cs файлы нужно разместить в соответствующих папках проекта. SDK-style .csproj автоматически включает файлы из подпапок.
5. Перед публикацией запусти GitHub Actions. Если сборка завершится ошибкой, пришли полный лог.

Существующий дизайн не изменён.
