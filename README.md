# Battery Taskbar

Небольшая программа для Windows 11: показывает заряд беспроводных устройств в левой части панели задач.

## Возможности
- Bluetooth LE и обычный Windows Battery API.
- Logitech на USB-приёмниках с HID++.
- Logitech G435 LIGHTSPEED (донгл `046D:0ACB`), по включению: заряд оценивается по напряжению.
- Мышь AJAZZ AJ159 APEX / AM Infinity 8K.
- Мыши Compx/Pulsar: VXE (в том числе R1 SE+), ATK, VGN, Pulsar (экспериментально).
- Виджет не мешает: клики проходят сквозь него (удобно в играх), поверх полноэкранных приложений его можно скрывать.
- Окно настроек в стиле Windows 11 со светлой и тёмной темой (выбирается автоматически по системе).
- Раздел «Диагностика и журналы» отдельно от основных настроек.

## Как пользоваться
- Иконка в трее: быстрое меню с зарядом устройств, «Обновить», «Переместить виджет», «Настройки…».
- **Переместить виджет:** кнопка в настройках или в меню трея (30 секунд виджет можно перетаскивать левой кнопкой мыши), либо удерживайте **Ctrl** и перетаскивайте. Без Ctrl клики проходят сквозь виджет.
- Виджет сам обходит значки панели задач и скрывается, если места нет.
- Устройства можно скрывать переключателями на странице «Устройства».

## Logitech G435

| USB ID | Поддержка | Примечание |
|---|---|---|
| `046D:0ACB` | есть, по включению | служебный режим донгла: на ~1 секунду приглушает звук и микрофон, опрос не чаще раза в 15 минут |
| `046D:0ADF` | нет | другая ревизия донгла: нужны тесты на реальном устройстве |

Процент G435 приблизительный: он считается по напряжению аккумулятора. Если после чтения звук не вернулся, достаточно вынуть и снова вставить донгл. Включается в настройках на странице «Наушники G435».

## Сборка из исходников
Нужен .NET 8 SDK и Windows:

```powershell
dotnet build .\BatteryTaskbar.csproj -c Release
```

Все `.cs`-файлы в корне проекта подключаются автоматически.

## Структура
- `BatteryService.cs`: интерфейс провайдера и объединение показаний.
- `Providers.cs`: Windows PnP, Battery API, Bluetooth LE.
- `LogitechHidpp.cs`: Logitech HID++. `LogitechG435Provider.cs`: G435.
- `VendorProviders.cs`: мышь AJAZZ. `CompxProvider.cs`: мыши Compx/Pulsar.
- `OverlayWindow.cs`, `TaskbarLayout.cs`: виджет и защита от наложения на значки.
- `SettingsWindow.cs`, `TrayController.cs`: окно настроек и меню в трее.
- `HidScanner.cs`: диагностика служебных каналов.

## Как добавить поддержку нового устройства
Напишите класс, реализующий `IBatteryProvider`, и добавьте его в `Program.cs`. Если устройство не определяется, откройте «Диагностика и журналы», запустите сканер и приложите журнал к Issue на GitHub.
