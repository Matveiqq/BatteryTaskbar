# Battery Taskbar

Маленькая программа для Windows 11: показывает заряд беспроводных устройств
(клавиатура, мышь, наушники, геймпад) в левой части панели задач.

## Возможности
- Заряд беспроводных устройств: Bluetooth и USB-донгл (приёмник)
- Иконка в трее (в скрытых значках, стрелка ^ рядом с часами). Клик по ней или по виджету открывает меню:
  - текущий заряд всех найденных устройств
  - какие устройства показывать на панели
  - тема оформления (пока одна: «Компактный»)
  - порог низкого заряда (красный цвет)
  - автозапуск вместе с Windows
- Подстраивается под светлую и тёмную тему Windows

## Какие устройства поддерживаются
- Bluetooth LE (мыши, клавиатуры, многие наушники)
- Классические Bluetooth-наушники
- Устройства на донглах, которые отдают заряд стандартным HID-способом (геймпады и др.)
- Logitech на приёмниках Unifying, Bolt, Lightspeed (протокол HID++)
- Razer, SteelSeries, Corsair и другие фирменные донглы пока не поддерживаются

## Установка
Скачайте `BatteryTaskbar.exe` из раздела [Releases](../../releases) и запустите.
Если SmartScreen предупреждает, нажмите «Подробнее» → «Выполнить в любом случае»
(файл пока не подписан сертификатом).

## Сборка из исходников
Нужен .NET 8 SDK и Windows:

    dotnet run

## Устройство проекта
- `BatteryService.cs`: `IBatteryProvider` (источник заряда) и `DeviceMonitor` (опрашивает все источники параллельно)
- `Providers.cs`: Bluetooth LE, заряд из Windows (PnP), Windows Battery API
- `LogitechHidpp.cs`: Logitech на приёмниках (HID++)
- `Themes.cs`: темы оформления (`IBatteryTheme`)
- `OverlayWindow.cs`: виджет на панели задач, `TrayController.cs`: иконка в трее и меню
- `HidScanner.cs`: диагностика служебных каналов донглов

## Как добавить поддержку нового бренда
Напишите класс, реализующий `IBatteryProvider`, и добавьте его в `Program.cs` в список провайдеров.
Если ваш донгл не определяется, запустите в меню трея «Сканер служебных каналов», откройте журнал
и приложите его к Issue на GitHub.

## Как добавить новую тему
Реализуйте `IBatteryTheme` и добавьте тему в `Themes.All` (файл `Themes.cs`). Пункт меню появится сам.
